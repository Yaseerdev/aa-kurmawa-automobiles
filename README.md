# AA Kurmawa Automobiles — Premium Website

## Phase 1
Premium Next.js prototype with:
- Cinematic homepage
- Dynamic vehicle-card architecture
- Vehicle detail routes
- Responsive navigation
- Motion/reveal animations
- Services, contact and appointment CTAs

## Run
```bash
npm install
npm run dev
```

Then open http://localhost:3000
